DocMind AI

Documento técnico de ejecución y estado actual del proyecto. Esta guía resume toda la construcción del MVP utilizando FastAPI, React, TypeScript y Docker.

1. Objetivo del Proyecto

DocMind AI es una plataforma inteligente orientada al procesamiento documental, extracción de información y ejecución de reglas deterministas. El sistema permite cargar documentos PDF y DOCX, extraer su contenido textual, analizarlo mediante reglas y devolver resultados estructurados.

2. Arquitectura del Sistema

Frontend

Interfaz desarrollada con React + TypeScript + Vite. Permite cargar documentos y visualizar resultados.

Backend

API REST desarrollada con FastAPI. Gestiona uploads, extracción documental y motor de reglas.

Extracción

Uso de pdfplumber y python-docx para lectura de archivos.

Motor de Reglas

Sistema determinista basado en condiciones evaluables sobre texto extraído.

4. Configuración del Frontend

Paso 1: Se creó el frontend utilizando Vite con React + TypeScript. 
npm create vite@latest . -- --template react-ts
Paso 2: Se instalaron las dependencias principales. 
npm install
npm install axios
npm install react-router-dom
Paso 3: Se implementó el componente principal App.tsx.

El componente permite:

  • Seleccionar archivos PDF y DOCX.
  • Enviar documentos al backend mediante Axios.
  • Mostrar resultados JSON en pantalla.
Frontend ejecutándose correctamente en: http://127.0.0.1:5173

5. Configuración del Backend

Paso 1: Se creó el entorno virtual Python. 
python3 -m venv .venv
source .venv/bin/activate
Paso 2: Instalación de dependencias. 
pip install fastapi uvicorn sqlalchemy pydantic python-multipart
pip install pdfplumber python-docx unstructured spacy
Paso 3: Creación de endpoints FastAPI.

El endpoint principal implementado fue: 

POST /upload
Paso 4: Implementación de CORS.

Se configuró el middleware CORSMiddleware para permitir comunicación entre React y FastAPI.

Backend ejecutándose correctamente en: http://127.0.0.1:8000

6. Flujo de Procesamiento

  1. Usuario selecciona documento.
  2. Frontend envía archivo mediante Axios.
  3. FastAPI recibe el archivo.
  4. El archivo se guarda temporalmente.
  5. Se extrae el texto del documento.
  6. El motor de reglas analiza el contenido.
  7. Se genera una respuesta JSON.
  8. React renderiza los resultados.

8. Motor de Reglas

El motor de reglas funciona mediante coincidencias y condiciones aplicadas sobre el texto extraído. 

if "ingeniero" in text:
    score += 2

if "5 años" in text:
    score += 3

El sistema devuelve:

  • Puntaje.
  • Reglas activadas.
  • Ranking.

9. Problemas Encontrados y Soluciones

Error TypeScript: Faltaban tipos de React. 
npm install -D @types/react @types/react-dom
Error Vite: Conflicto de versiones entre vite y plugin-react. 
npm install -D @vitejs/plugin-react@4.3.1
Error CORS: FastAPI bloqueaba peticiones desde React.

Solucionado mediante CORSMiddleware.
